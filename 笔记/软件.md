#### Previleged Instruction

Set value of system timer 是，设置系统定时器会影响系统时钟中断和进程调度，不能让普通用户随意修改。
Read the clock            不是，读取时钟只是获取时间信息，不会改变系统状态，一般允许用户程序读取。
Clear memory              是,如果指清除任意物理内存或系统内存，可能破坏操作系统和其他进程的数据，因此需要特权。
Issue a system call instruction 不是，	用户程序必须能够主动发起系统调用，因此系统调用指令本身允许在用户模式执行。
Turn off interrupts       是,关闭中断会影响整个处理器的中断响应，普通用户程序不能随意关闭。
Modify entries in the page table  是,修改页表会改变虚拟地址到物理地址的映射，涉及内存保护和系统安全，必须由操作系统管理。
Access I/O device         是，必须能够做到输入输出

#### System call的类型

拷贝一个文件需要系统调用

标准输入和标准输出可以用文件描述符表示

```
标准输入（stdin）：文件描述符为 0，默认从键盘读取数据。
标准输出（stdout）：文件描述符为 1，默认向屏幕输出数据。
标准错误（stderr）：文件描述符为 2，默认向屏幕输出错误信息。
```

示例：

```c
#include <stdio.h>

int main() {
    int a;
    scanf("%d", &a);
    printf("%d\n", a);
    return 0;
}
```

scanf()默认从标准输入读取数据(stdin,FD=0)，printf()默认向标准输出打印数据(stdout,FD=1)。
